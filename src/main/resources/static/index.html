Government Training Management

Manage programmes and nominate officers across departments.

Nominate an officer

Each officer can be nominated once per training programme, even by different departments. If a programme is full, the officer is placed on a waiting list and confirmed automatically when a seat opens up.

Getting started

Add departments first, then officers and training programmes. Use the nomination form to register an officer for a programme.

The server checks for duplicate nominations, and waitlists officers automatically once a programme reaches capacity. Use Edit / Delete in the tables below to manage existing records.
